## Variant-specific changes

- FlashAttention's CMake Python allowlist ends at 3.13. Apply `flash-attn-python314.patch` in the FlashAttention vendor root before building.
- The 0.29 `vllm-cu132-topk.patch` is no longer needed: 0.33.0 no longer contains the GCC-specific `__FLT_MAX__` it replaced.
- The optimized `vllm-rs.exe` from the Python 3.13 build was reused; it does not depend on Python or CUDA. All CUDA/C++ extensions were rebuilt.

## Validation record

The exact installed wheel was tested outside the source tree on RTX 3090.

- Native build completed without source changes beyond the Python 3.13 port. Wheel archive integrity, RECORD hashes, metadata, native payload, rewritten CuTe files and Windows-specific source markers passed.
- Installed-wheel version, location, native module imports, expected operators and `vllm-rs 0.33.0` passed.
- Slot-mapping fallback and shared offload region tests: 46 passed; 24 skipped (POSIX-only or CUDA-without-Triton cases). Windows process and socket guards passed.
- FP8 Marlin padded LM head, with and without bias: relative L2 0.223% and 0.276%, identical to the Python 3.13 build. SM120 metadata was mocked while kernels ran on the 3090.
- All six local cache formats passed backend write/decode checks with results identical to the Python 3.13 build.
- Real-model serving: Qwen3.5-9B GPTQ, Triton attention, compilation and CUDA graphs. Ordinary and streaming chat returned the same correct answer.
- CPU-ARC offload with the pinned host region: 1,056 cached tokens restored from a 1,452-token prompt with identical generated token IDs, and no host-registration warning.

Not validated: GPU TorchAudio and audio-model serving, filesystem offload modes, the multi-process socket-handoff path, other model families and Blackwell hardware. Native Blackwell FP4 is not included.
