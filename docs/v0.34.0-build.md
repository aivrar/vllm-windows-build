## Port changes

Astemiir supplied the foundational v14 Windows port. It adapts vLLM's rewritten KV offload code, resolves CUDA/MSVC compilation problems, and fixes Windows runtime imports. The release builds also include the Windows Rust build fixes, a Qwen3.5 fallback when FlashInfer is unavailable, and the FlashInfer top-k opt-out. The included launcher supports the single-token warm-up and its opt-out. [Astemiir's port and findings](https://github.com/aivrar/vllm-windows-build/issues/23)

Use the [source build instructions](install.md#build-from-source) with the matching CUDA toolkit and PyTorch wheel. Preserve LF when applying vendor patches on Windows. Build the Rust release executable before compiling the CUDA extensions, and assemble the wheel from the local binaries. The native core and MoE libraries in this version are _C_stable_libtorch.pyd and _moe_C_stable_libtorch.pyd. Pass the resulting wheel path to tests/test_wheel_contents.py.

For Python 3.14, use CUDA 13.2, the tag's constraints-cu132-py314.txt and the FlashAttention flash-attn-python314.patch from the release. Apply that patch inside the pinned vllm-flash-attn checkout, and set VLLM_FLASH_ATTN_SRC_DIR to that checkout. The installer uses CPU TorchAudio. TorchCodec video input requires compatible shared FFmpeg DLLs.

## RTX 3090 validation

Both exact wheels installed into fresh portable environments and executed Triton and FlashAttention CUDA operations. Each served Qwen3.5-9B GPTQ with TRITON_ATTN, eager execution and an INT8 per-token-head KV cache. With launcher warm-up disabled, the first chat request answered 2 + 2 correctly.

All six Multi-TurboQuant formats passed cache write/decode checks. The padded FP8 Marlin output layer matched the reference with relative L2 errors of 0.223% without bias and 0.276% with bias. The selection check simulated SM 12.0 metadata while running kernels on the RTX 3090. CPU ARC offload restored 1,152 of 1,452 prompt tokens after clearing the GPU prefix cache and reproduced all eight output tokens on both runtimes.

These wheels omit native Blackwell FP4 acceleration. The 0.33.0 experimental SM120 source add-on is documented separately. This release's tests cover the RTX 3090 and CPU restore. The filesystem tier and other GPU architectures have no new hardware result in this release.
