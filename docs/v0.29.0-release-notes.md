# vLLM 0.29.0 Windows prerelease

Prerelease `v0.29.0-win-cu130-rc1`. Version 0.27.1 remains stable and Latest.

This update brings the native Windows port to upstream vLLM 0.29.0. It retains the CPython 3.13, PyTorch 2.13.0+cu130 and Triton Windows 3.7.1.post27 stack. The existing Multi-TurboQuant 0.1.0 companion wheel is reused; only the vLLM wheel is rebuilt.

## Issue #16

The candidate includes the FP8 LM-head partition metadata needed by Marlin and corrects native CUTLASS FP8 availability reporting. Automatic Windows backend selection prefers Marlin when the compiled CUTLASS implementation is unavailable. This removes the need for the reporter's manual Python edit and the old `VLLM_TEST_FORCE_FP8_MARLIN` workaround.

The maintained launcher also accepts `--linear-backend`, for example `--linear-backend marlin`. Leave it on automatic selection for the first tester run so the default fallback is exercised.

Native SM120 CUTLASS FP8/NVFP4 specializations remain omitted because of the Windows compiler limitations. Generic SM120 code in the wheel does not establish support for those specializations. RTX 3090 validation cannot confirm execution on Blackwell; the issue #16 reporter's test is still required.

## Preserved Windows features

- Native CUDA extensions, FlashAttention payloads, Rust frontend and Rust tool parser.
- Six local Multi-TurboQuant cache formats alongside the four upstream TurboQuant formats; the local writer is adapted to the new attention-cache layout.
- CPU and filesystem KV offload with LRU/ARC policies, Windows shared-memory handling and native CUDA copy fallbacks.
- Windows process startup, socket, weight-loader and sampling fixes, adapted to the relocated upstream server entry points.

The legacy `--num-scheduler-steps` launcher argument now accepts only `1`; larger values fail with an explanation before model loading because current vLLM no longer exposes that engine option.

## Testing the candidate

Use a separate installation and a fresh filesystem-cache directory. Keep the working 0.27.1 installation available while testing. Version 0.27.1 remains the stable release.

Download the **Source code (zip)** from this prerelease, extract it to a new directory, and run `install.bat`. This tag's installer downloads and verifies the 0.29.0 wheel and unchanged Multi-TurboQuant companion. The default `master` branch still installs stable 0.27.1.

The exact installed wheel passed native-payload checks, real-model ordinary and streaming chat with compilation/CUDA graphs on RTX 3090, the padded FP8 LM-head Marlin regression, and all six local KV-format write/decode checks. See the build record for cache-restoration results and hardware limits.

For issue #16, use the same model revision and launch settings as the working baseline, remove the old force-Marlin environment setting, and leave backend selection automatic. Report the selected linear backend, successful startup and chat request, or the complete traceback with credentials removed. Separate cold compilation time from warmed throughput.

The [build record](v0.29.0-build-candidate.md) tracks the exact source, dependency pins and completed validation.
